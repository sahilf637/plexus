# Plexus P1 — polish: first-run setup, a better side panel, a real reader

## Context

M0–M4 work, but a new user lands on an empty map with no idea what to set up, and anything
longer than a paragraph is hard to read in a 400 px panel (PDFs show their extracted text in a
grey box, saved articles lose their pictures). P1 fixes both before M5 (scale, imports, MCP).

Decided (2026-10-06):
- **Setup is a short guided flow on first run, and every step can be skipped.** AI stays optional
  (principle 3): "Use without AI" is a first-class choice, not a hidden link.
- **The shortcut is registered during setup, not at launch**, so the desktop's own approval dialog
  (GNOME on Wayland) shows up when the user is looking at the shortcut step, not on top of the
  welcome screen.
- **Changing the library folder restarts the app.** The library is opened once at startup; a
  restart at the end of setup is simpler and safer than swapping it live.
- **The panel has two widths**: the docked panel (peek: summary, links, details) and a wide
  reader for reading the item itself. Same component, so links and actions stay at hand.
- **PDFs are rendered with pdf.js** (`pdfjs-dist`) inside the reader. Web views differ in whether
  they show PDFs at all (WebKitGTK doesn't), so the app brings its own.
- **Pictures in saved articles load from the web** when the reader shows them (the page itself was
  already fetched to read it). They are never downloaded into the library.

## A. First-run setup

Shown instead of the map while `setupDone` is false. `setupDone` defaults to false for a new
settings file and to true for a settings file written before it existed, so existing users never
see it. Settings → General has "Run setup again".

1. **Welcome** — what Plexus does in three lines (copy → it connects → explore and ask).
2. **Library** — where notes live (default `~/Plexus`), "Choose another folder…" with the system
   folder picker. Says how many notes a chosen folder already has. A different folder is saved and
   the app restarts when setup ends.
3. **AI (optional)** — "Use without AI" or connect a provider with the same form as Settings (the
   form becomes one component, `ProviderForm.svelte`). The key is tested before it is kept.
   Connecting turns on "Improve new notes".
4. **Shortcut** — turns the global shortcut on here (on Wayland the desktop asks to approve it),
   shows the keys that were bound, what it does (open the window / save the clipboard), and start
   at login. Clipboard watching is offered, off by default.
5. **Done** — how to add the first thing (shortcut, Ctrl+V on the map, drag and drop).

## B. Side panel and reader

1. **Header**: kind chip, title once scrolled, then only Ask, Expand and Close; open file, open
   link, copy and delete move into a "More" menu.
2. **Reader width**: Expand (`E`) widens the panel to a reading column (up to ~860 px, the map stays
   visible beside it); the choice is remembered. The map's inset follows the panel's width.
3. **Typography**: a reading column with a comfortable measure and line height, headings, quotes,
   lists, tables and code styled for reading.
4. **PDFs**: pages rendered with pdf.js, lazily as they scroll into view; the extracted text stays
   available under "Text found".
5. **Images**: click to open full size (a lightbox with zoom); Esc closes.
6. **Articles**: their pictures show (CSP allows `https:` images); the source line links out.
7. **Citations land on the quote**: opening a source from an Ask answer scrolls the note to the
   quoted words and highlights them; for PDFs it opens the page they are on.

## Status

Implemented (2026-10-06). Notes:
- `setupDone` is set by finishing or skipping; Settings → General → Setup runs it again.
- The library step only records the folder; the switch (and restart) happens at "Restart and open
  the library" on the last step.
- pdf.js (`pdfjs-dist`, legacy build for older web views) is a separate chunk loaded with the first
  PDF; its fonts, character maps and image decoders are served from `/pdfjs/` (copied by a small
  Vite plugin). The CSP allows `asset:` for `connect-src` (pdf.js reads the file),
  `'wasm-unsafe-eval'` (its image decoders) and `https:` images (pictures in saved articles).
- The reader width is remembered per computer (`plexus.readerWide`); in the wide reader the map
  keeps about 160 px visible.
- Quotes are found ignoring spacing, case and markdown marks, falling back to their first words;
  for PDFs the page comes from the extracted text's page marks, then the page's text layer is
  marked once drawn.
- Links inside notes open in the browser (`open_url`, http/https only) instead of navigating the
  window.
